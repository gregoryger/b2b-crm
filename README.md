# B2B CRM

CRM-система для управления продажами корпоративным клиентам: лиды, клиентская база, воронка сделок,
коммерческие предложения, счета и оплаты, задачи и напоминания, аналитика. Разработана по техническому
заданию «Разработка собственной CRM-системы (B2B)», версия 1.0.

## Быстрый старт

Нужен Docker (Docker Desktop или Docker Engine + Compose v2).

```bash
cp .env.example .env          # задайте SECRET_KEY, FIELD_ENCRYPTION_KEY и пароли
docker compose up -d --build
docker compose exec backend python -m app.seed --demo   # демо-данные (или без --demo — только справочники и admin)
```

| Сервис | Адрес |
|---|---|
| Система | http://localhost:8080 |
| API и Swagger | http://localhost:8080/api/docs |
| Тестовая почта (все письма CRM) | http://localhost:8025 |
| Хранилище файлов MinIO | http://localhost:9001 |

## Возможности

- **Клиенты**: компании с реквизитами (проверка ИНН, защита от дублей), контакты с ролями ЛПР/влияющий/технический,
  хронологическая лента взаимодействий, фильтры и сегменты, глобальный поиск по названию/ИНН/телефону/ФИО,
  импорт из CSV/Excel с сопоставлением колонок, выгрузка сегментов.
- **Лиды и сделки**: приём заявок с сайта (REST + API-ключи), из почты (IMAP-парсер), с телефонии, вручную;
  автораспределение (по очереди / наименее загруженному); конвертация «лид → сделка + компания + контакт»
  в один клик; настраиваемая воронка с вероятностями; канбан с drag-and-drop; товары, участники, файлы.
- **Задачи**: звонки, встречи, письма, КП; календарь день/неделя/месяц с переносом мышью; подписка в
  Google Calendar / Outlook (ICS); напоминания за 15 мин / 1 час / 1 день в интерфейс, на email и в Telegram.
- **Коммерческие предложения**: шаблоны под отрасли, переменные, каталог с ценами и скидками, PDF в фирменном
  стиле, отправка с отслеживанием открытия, онлайн-версия с согласованием клиентом.
- **Финансы**: счета и акты в PDF (сумма прописью), оплаты и частичные оплаты, дебиторская задолженность по
  срокам, выгрузка в 1С (XML).
- **Аналитика**: дашборд руководителя, воронка, эффективность менеджеров, источники лидов (CPL, CAC, ROI),
  продукты и маржа, конструктор отчётов, экспорт в PDF/Excel/CSV, рассылка по расписанию.
- **Администрирование**: пользователи и роли, справочники, этапы воронки, каталог, пользовательские поля,
  шаблоны КП, интеграции, журнал аудита.
- **Безопасность**: JWT (access + refresh с ротацией), 2FA (TOTP), блокировка при переборе паролей,
  шифрование телефонов в БД, разграничение данных по ролям, rate limiting, аудит.

## Стек

Python 3.12 · FastAPI · SQLAlchemy 2 · Alembic · PostgreSQL 16 · Redis · Celery · MinIO (S3) · WeasyPrint ·
React 18 · TypeScript · Mantine · TanStack Query · Docker Compose.

## Структура

```
backend/
  app/api/v1/        REST-эндпоинты по модулям
  app/models/        модели БД
  app/services/      бизнес-логика: доступ, аналитика, документы, почта, телефония
  app/worker/        фоновые задачи Celery (напоминания, отчёты, IMAP, Telegram)
  app/templates/     шаблоны PDF (КП, счёт, акт, отчёт)
  alembic/           миграции БД
  tests/             автотесты API и нагрузочный сценарий (tests/load)
frontend/src/
  pages/             экраны системы
  components/        общие компоненты (формы, лента, задачи, файлы, поиск)
scripts/             резервное копирование и восстановление
docs/                документация
```

## Разработка

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d   # бэкенд с автоперезагрузкой
cd frontend && npm ci && npx vite build                                 # nginx отдаёт свежую сборку
```

Тесты (33 интеграционных теста API на отдельной БД):

```bash
docker compose run --rm backend sh -c "pip install --user -q pytest && python -m pytest -q"
```
