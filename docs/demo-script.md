# Сценарий демонстрации заказчику (30–40 минут)

Подготовка: `docker compose up -d`, демо-данные загружены (`python -m app.seed --demo`). Откройте две вкладки:
систему (http://localhost:8080) и тестовую почту (http://localhost:8025) — в ней видно письма, которые «уходят» клиентам.
Пароль всех демо-пользователей: `demo12345`.

## 1. Руководитель: картина продаж (5 мин) — ТЗ 3.5, 6.1

Вход: **head@demo.ru**.

1. **Дашборд**: выручка, выигранные сделки, средний чек, конверсия лидов — со сравнением с прошлым периодом.
   Переключите период на «12 месяцев» — выручка по месяцам. Выберите менеджера в фильтре «Весь отдел».
2. Блок «Воронка продаж» — сколько денег на каждом этапе сейчас; «Прогноз закрытия» — ожидаемая выручка по месяцам
   с учётом вероятности этапов.
3. «Топ менеджеров» → «Подробнее» → отчёт «Эффективность менеджеров».

## 2. Лид с сайта → сделка за минуту (7 мин) — ТЗ 3.2, 4.5

1. Отправьте заявку, как это сделает сайт (или покажите готовый код формы в «Администрирование → Интеграции»):
   ```bash
   curl -X POST http://localhost:8080/api/v1/public/leads -H "X-Api-Key: crm_demo_website_key_2026" \
     -H "Content-Type: application/json" \
     -d '{"name":"Иван Смирнов","company":"ООО Демонстрация","phone":"+79161234567","email":"ivan@demo.example","message":"Нужны 3 сервера"}'
   ```
2. Войдите менеджером, которому ушёл лид (он указан в «Лиды»), — у него в колокольчике уведомление «Новый лид».
3. Откройте лид → «Взять в работу» (фиксируется время реакции) → кнопка звонка у телефона (click-to-call) →
   «Конвертировать в сделку»: в один клик созданы сделка, компания и контакт.

## 3. Менеджер: работа со сделкой (10 мин) — ТЗ 3.1–3.4

Вход: **petrov@demo.ru** — менеджер видит только свои сделки и клиентов (ТЗ 4.3).

1. **Сделки → Канбан**: перетащите карточку на следующий этап. ⚠ — сделки без активности 14+ дней.
2. Карточка сделки → «Товары и услуги»: добавьте позиции из каталога со скидкой — сумма пересчитается.
3. «⋯ → Создать КП» → шаблон подставил реквизиты клиента → «PDF» (логотип, фирменный стиль) →
   «Отправить клиенту». Письмо появится в тестовой почте.
4. Откройте ссылку на онлайн-версию КП из письма (или «Ссылка для клиента → Открыть») — это то, что видит клиент.
   Нажмите «Согласовать» — у менеджера придёт уведомление, статус КП и лента сделки обновятся.
5. «Выставить счёт по КП» → «Счета и оплаты» → PDF счёта с суммой прописью → «Добавить оплату» → «Сформировать акт».
6. Задача «Позвонить» с напоминанием за 15 минут → «Календарь» → перенос задачи мышью → «Синхронизация»
   (ссылка для Google Calendar / Outlook).
7. Горячие клавиши: `/` — поиск по ИНН или телефону в любом формате, `C` — новая сделка, `?` — все клавиши.

## 4. Карточка клиента (3 мин) — ТЗ 3.1, 6.1

Компании → фильтр «Нет контакта 30+ дней» → карточка компании: вкладки, лента всех событий справа (звонки, письма,
изменения полей «было → стало»), задачи. «Выгрузить сегмент» — Excel для рассылки. «Импорт» — загрузка базы из Excel.

## 5. Маркетолог: эффективность каналов (4 мин) — ТЗ 3.5

Вход: **marketer@demo.ru**: нет доступа к сделкам (ТЗ 4.3), есть лиды и отчёты.
Отчёты → «Источники лидов»: конверсия, стоимость лида, стоимость продажи и ROI по каналам (бюджеты — в
«Администрирование → Маркетинговые бюджеты»). «Конструктор отчётов»: лиды по источникам, круговая диаграмма.
«Экспорт → Excel».

## 6. Администратор: настройка и контроль (5 мин) — ТЗ 3.6, 4.3

Вход: **admin@demo.ru**.

1. «Пользователи и роли» — матрица прав; создание сотрудника (временный пароль уходит на почту).
2. «Воронка» — добавить этап, поменять вероятность. «Доп. поля» — добавить поле «Количество филиалов» к компаниям.
3. «Журнал аудита» — удаления, изменения сумм, выгрузки базы, входы с IP.
4. Профиль → включить двухфакторную аутентификацию (QR-код для Яндекс Ключа / Google Authenticator).
5. http://localhost:8080/api/docs — документация API для интеграций.

## Частые вопросы заказчика

| Вопрос | Ответ |
|---|---|
| Где хранятся данные? | На вашем сервере или в вашем облаке (PostgreSQL + S3). Никаких внешних SaaS. |
| Как подключить нашу АТС / почту / 1С? | См. docs/deployment.md, раздел 8. Для телефонии нужен адаптер под вашу АТС — этап 3 плана работ. |
| Сколько пользователей выдержит? | Нагрузочный тест: 50 одновременных пользователей и 1500+ компаний в списках — см. docs/load-test.md. Масштабирование до 500 — добавлением реплик, без переделки. |
| Что с резервными копиями? | Ежедневно, хранение 30 дней, восстановление одной командой. |
| Можно ли поменять воронку, поля, шаблоны без программиста? | Да, в разделе «Администрирование». |
