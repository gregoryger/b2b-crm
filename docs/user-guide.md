# Руководство пользователя CRM

Онлайн-версия руководства — раздел **«Помощь»** в системе. Там же можно заново пройти обучающий тур.

## 1. Начало работы

1. Откройте адрес системы и войдите по корпоративному email. Первый пароль приходит на почту; система попросит его сменить.
2. При первом входе пройдите короткий тур по интерфейсу (1 минута).
3. Заполните профиль (**меню пользователя → Профиль**): должность и телефон подставляются в КП и письма.
   Там же настройте уведомления (email, Telegram) и при желании включите двухфакторную аутентификацию.

### Роли

| Роль | Возможности |
|---|---|
| Менеджер | Свои клиенты, лиды, сделки, задачи; КП, счета; свои показатели |
| Руководитель | Все данные отдела, передача клиентов и сделок, отчёты по команде, журнал аудита, настройка воронки |
| Маркетолог | Все лиды, источники, маркетинговые бюджеты, отчёты по каналам, выгрузка сегментов, импорт |
| Администратор | Пользователи, справочники, поля, интеграции, настройки системы |

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `/` или `Ctrl+K` | Глобальный поиск |
| `C` | Новая сделка |
| `L` | Новый лид |
| `T` | Новая задача |
| `N` | Новая компания |
| `?` | Список клавиш |
| `Ctrl+Enter` | Сохранить заметку в ленте |

## 2. Дашборд

Главная страница: выручка, выигранные сделки, средний чек, конверсия лидов, сумма в работе, взвешенный прогноз,
время реакции на лид, просроченные задачи — со сравнением с прошлым периодом. Ниже — выручка по месяцам,
воронка, прогноз закрытия, ваши задачи на сегодня и последние события. Руководитель может выбрать менеджера.

## 3. Лиды

Лид — входящий запрос, который ещё не стал сделкой. Лиды поступают автоматически (сайт, почта, звонки, API)
или создаются вручную (`L`). Новые лиды распределяются между менеджерами, ответственный получает уведомление.

1. Откройте лид → **«Взять в работу»**. Время первого ответа учитывается в KPI.
2. Свяжитесь с клиентом: кнопка звонка рядом с телефоном (через АТС), «Письмо», заметка в ленте.
3. Целевой запрос → **«Конвертировать в сделку»**: система предложит существующую компанию, если найдёт совпадение
   по ИНН, названию, телефону или email. В один клик создаются сделка, компания и контакт.
4. Нецелевой → **«Отклонить»** с причиной.

## 4. Компании и контакты

- **Список компаний**: фильтры по отрасли, региону, статусу, ответственному, сумме покупок и давности контакта.
  «Нет контакта 30+ дней» — клиенты, которым пора позвонить.
- **Карточка компании**: вкладки «Инфо», «Контакты», «Сделки», «КП и счета», «Файлы», «История» (переписка);
  справа — задачи и лента всех событий по клиенту, включая сделки и контакты.
- При вводе ИНН система проверяет контрольную сумму и предупреждает о дублях.
- **Импорт**: Компании → Импорт → загрузите CSV/Excel → проверьте сопоставление колонок → «Импортировать».
- **Выгрузка сегмента**: настройте фильтры → «Выгрузить сегмент» → Excel с компаниями и контактами.

## 5. Сделки

- **Канбан**: перетаскивайте карточки между этапами. Над колонкой — количество, сумма и прогноз этапа.
  Значок ⚠ — нет активности 14+ дней; красная дата — просрочена плановая дата закрытия.
- **Карточка сделки**: полоса этапов (клик — перенос), кнопки «Выиграна» / «Проиграна» (для проигрыша нужна причина).
  - «Товары и услуги» — позиции из каталога, количество, скидки; сумма сделки пересчитывается.
  - «Документы» — КП, счета, файлы (договоры, презентации).
  - «История этапов» — когда и сколько сделка провела на каждом этапе.
  - Участники: контактные лица клиента с ролями и сотрудники, подключённые к сделке.

## 6. Задачи и календарь

- Создавайте задачи из карточек или клавишей `T`: тип, срок, длительность, исполнитель, приоритет, напоминание.
- Раздел **«Задачи»**: сегодня, просроченные, предстоящие, выполненные; фильтр «Поручил я».
- При завершении укажите результат — он попадёт в ленту клиента.
- **Календарь**: день / неделя / месяц, перенос задач мышью, создание встречи кликом по времени.
  «Синхронизация» — ссылка для подписки в Google Calendar или Outlook.

## 7. Коммерческие предложения

1. В карточке сделки: **⋯ → Создать КП** (позиции сделки подставятся автоматически).
2. Отредактируйте заголовок, вступление, позиции, условия. «Переменные» вставляют реквизиты клиента, ФИО менеджера,
   срок действия, итоговую сумму.
3. **PDF** — предпросмотр в фирменном стиле с логотипом.
4. **«Отправить клиенту»** — письмо с PDF и ссылкой на онлайн-версию. Когда клиент откроет письмо или КП,
   придёт уведомление, статус сменится на «Просмотрено».
5. Клиент может нажать «Согласовать» или «Отклонить» прямо в онлайн-версии. Статус можно поменять и вручную.
6. Изменения после согласования — через «Новая версия КП». По согласованному КП — «Выставить счёт».

## 8. Счета и оплаты

- Счёт выставляется из сделки или КП: позиции переносятся автоматически, срок оплаты — 5 дней (меняется).
- В карточке счёта: PDF, фиксация оплат (в т. ч. частичных), формирование акта.
- Вкладка «Дебиторка по срокам» — задолженность по периодам просрочки.
- «Выгрузка в 1С» — XML со счетами, актами и контрагентами за период.

## 9. Отчёты

| Отчёт | Что показывает |
|---|---|
| Сводный | Ключевые показатели за период |
| Воронка продаж | Сколько сделок дошло до каждого этапа, конверсия, среднее время на этапе |
| Эффективность менеджеров | Новые, выигранные и проигранные сделки, win rate, выручка, средний чек, активность, просрочки |
| Источники лидов | Лиды, конверсия, продажи, выручка, бюджет, стоимость лида и продажи, ROI по каналам |
| Продуктовая аналитика | Продажи по продуктам, выручка, себестоимость, маржинальность |
| Дебиторская задолженность | Неоплаченные счета и структура по срокам |
| Конструктор | Любой показатель по дням, неделям, месяцам, менеджерам, источникам, отраслям, регионам, этапам; графики: столбцы, линия, круговая |

Все отчёты выгружаются в PDF, Excel и CSV. «Рассылка по расписанию» — отчёт на email еженедельно или ежемесячно.

## 10. Уведомления

Колокольчик в шапке — новые лиды, назначенные задачи, напоминания, открытие КП, оплаты, входящие звонки.
Те же уведомления можно получать на email и в Telegram (**Профиль → Уведомления → Подключить бота**).

## 11. Администрирование

| Раздел | Назначение |
|---|---|
| Пользователи и роли | Создание учёток (доступ уходит на email), блокировка, сброс пароля и 2FA, внутренние номера SIP; матрица прав |
| Воронка | Этапы, вероятность, цвет, порядок |
| Справочники | Отрасли, регионы, типы клиентов, источники, причины отказа |
| Продукты и услуги | Каталог с ценами и себестоимостью (для маржи) |
| Доп. поля | Свои поля для компаний, контактов, сделок, лидов: текст, число, дата, список, флажок |
| Шаблоны КП | Тексты, условия, фирменный цвет, привязка к отрасли |
| Маркетинговые бюджеты | Расходы по каналам по месяцам — для CPL и ROI |
| Интеграции | API-ключи и код формы для сайта; статус почты, телефонии, Telegram, 1С |
| Компания и настройки | Реквизиты и логотип для документов, распределение лидов, курсы валют |
| Журнал аудита | Кто, когда и что изменил: входы, удаления, изменения сумм, экспорт |
